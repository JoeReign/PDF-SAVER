Handbook PDF Saver

Run this in your signed-in Thinkific lesson to save the loaded handbook. No installation, password entry, or external libraries needed. The script adds a small save panel and requests a local download.

  1. Open your Python Handbook lesson and wait until a PDF page appears.
  2. Open Developer Tools with F12 or Ctrl + Shift + J, then select Console.
  3. Click Copy script below, paste into Console, and press Enter. Chrome may restrict pasting: read its warning and only proceed if you understand the code. You can inspect the script in the box or the included JS file.
  4. If it says no document was found, use Console’s context dropdown (usually labeled top) to select the PDF viewer iframe, often named viewer.html. Paste and run again.
  5. Click Save original PDF in the new panel. If that fails, try Save all pages as images in a PDF. Keep the tab open until finished.

The image option renders every page from the loaded document, in order, without needing to scroll. It preserves page proportions but has no selectable text or links, and can use substantial memory. Cancel stops rendering; it never saves a partial PDF.

Compatibility: viewers exposing PDFViewerApplication.pdfDocument. The screenshot resembles this viewer, but the signed-in lesson has not been tested. If no viewer frame works, send a screenshot of the Console context dropdown and the error message.
