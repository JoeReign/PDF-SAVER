PDF Saver

Save a document from a compatible PDF.js viewer. Run the script on the page where your PDF is already open.

  1. Open the PDF and wait for a page to appear.
  2. Press F12 or Ctrl + Shift + J and select Console.
  3. Copy the script below, paste it into Console, and press Enter. Read any paste warning and review the code before proceeding.
  4. If the viewer isn't found, change the Console context from top to the PDF viewer frame, often named viewer.html, and run it again.
  5. Choose Save original PDF or Save all pages as images in a PDF in the new panel.

Which option?

The original PDF keeps text and links. The image option renders every page in order without scrolling, but loses selectable text and links. Large documents can take time and use a lot of memory. Keep the tab open until it finishes.

This works with viewers exposing PDFViewerApplication.pdfDocument. Chrome's built-in PDF viewer and other viewer types aren't supported.
